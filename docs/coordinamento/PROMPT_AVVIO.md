# Prompt di avvio — identico per le due sessioni di lavoro

Incollare il testo qui sotto **così com'è** in ciascuna delle due nuove sessioni Claude Code aperte su questo progetto.
Il nome della sessione di coordinamento cambia a ogni riavvio di VS Code: se la memoria è stata riavviata, aggiornare il nome nella prima riga prima di incollare.

---

```
Lavori al progetto PracticeHub (cartella MEGADASHBOARD-main), all'interno di un gruppo di tre sessioni Claude Code.

La sessione di coordinamento e memoria del progetto si chiama: megadashboard-main-6c

Prima di fare qualunque altra cosa:
1. Usa ListAgents e leggi il nome della TUA sessione (la riga "This session is …").
2. Mandami con SendMessage, all'indirizzo megadashboard-main-6c, un messaggio di presentazione con: il tuo nome di sessione, e una conferma che hai letto questo prompt.
3. Poi aspetta la mia risposta: ti comunicherò il tuo ruolo (backend o frontend), le regole del gruppo e il primo compito.

Finché non ricevi il ruolo:
- non modificare nessun file e non eseguire comandi git;
- puoi solo leggere CLAUDE.md e docs/coordinamento/STATO.md per orientarti.

Regole di comunicazione:
- Parla solo con megadashboard-main-6c. Sul computer ci sono anche sessioni di altri progetti: non scrivere a nessun'altra sessione.
- Rispondi sempre in italiano.
```
